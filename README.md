# 근태계획 웹앱 (구글시트 + Apps Script)

엑셀을 돌려서 취합하던 근태계획을, 모두가 휴대폰으로 동시에 접속해 바로 고치는 웹앱으로 바꾼 것입니다.
데이터는 구글시트에 저장되고, 무료 구글 계정 하나(관리자)로 운영됩니다.

## 기능 요약

| 구분 | 내용 |
|---|---|
| 접속 | 링크로 접속 → 본인 이름 선택 (기기에 기억). 관리자는 비밀번호 추가 입력 |
| 수정 | 내 일정 달력에서 날짜를 누르면 근태 목록에서 선택. 15초마다 다른 사람 변경이 자동 반영 |
| 권한 | 팀원: 본인 일정만 / 관리자: 모든 일정, 인원 추가·빼기·순서, 관리자 지정, 근태 목록 편집, 변경 이력 |
| 보기 | 이번 달(N)·다음 달(N+1) 두 탭. 달이 걸치는 주는 양쪽 탭에 같은 데이터로 표시. 전체 일정 표·일자별 인원 집계 |
| 자동 | 매월 21일 다다음 달(N+2) 생성 — 사람마다 전 달 최다 근무형태로 월~토(공휴일 포함), 일요일 빈칸, 모르면 "주간" |
| 알림 | 모든 변경을 `변경이력` 탭에 기록, 매일 15시 관리자에게 요약 메일 |
| 추출 | 누구나 "엑셀로 내려받기" → 기존 엑셀 양식(주 단위 표, 근태별 개수, 하단 집계표, 시간별 근무인원) 그대로 |

## 설치 (관리자 1명이 한 번만, 약 15분)

### 1. 구글시트와 코드 넣기
1. PC에서 [sheets.new](https://sheets.new) 로 새 구글시트를 만들고 이름을 정합니다 (예: `근태계획`).
2. 메뉴 **확장 프로그램 > Apps Script** 를 엽니다.
3. 왼쪽 파일 목록에서 아래 파일을 만들고, 이 저장소 `src/` 폴더의 내용을 그대로 붙여넣습니다.
   - `Code.gs` 는 지우거나 비워두고, **+ > 스크립트** 로 `Logic`, `Store`, `Api`, `Jobs`, `Export`, `Import`, `Setup` 7개 (.gs 는 자동으로 붙음)
   - **+ > HTML** 로 `Index` 1개 → `src/Index.html` 내용
4. 왼쪽 **⚙ 프로젝트 설정** 에서 *"편집기에서 appsscript.json 매니페스트 파일 표시"* 를 켜고, `appsscript.json` 을 `src/appsscript.json` 내용으로 바꿉니다. (시간대 `Asia/Seoul` 포함)
5. 저장(Ctrl+S) 후 구글시트 탭을 **새로고침** 하면 상단에 **근태관리** 메뉴가 생깁니다.

### 2. 처음 설정
1. **근태관리 > 1. 처음 설정** 실행 → 처음 한 번 구글 권한 승인 창이 뜹니다.
   ("확인되지 않은 앱" 경고가 나오면 *고급 > (프로젝트 이름)으로 이동* → 허용. 본인이 만든 스크립트라 안전합니다.)
2. `인원`, `근태코드`, `조직표기`, `설정`, `변경이력` 탭과 자동 실행(매일 01시 일정 확인/생성, 매일 15시 요약 메일)이 만들어집니다.

### 3. 기존 엑셀 명단·일정 가져오기
1. 구글시트 메뉴 **파일 > 가져오기 > 업로드** 에서 기존 근무표 엑셀(예: `10월 근태계획.xlsx`)을 고르고 **"새 시트 삽입"** 을 선택합니다.
2. **근태관리 > 2. 엑셀 양식에서 가져오기** 실행 → 명단(소속·구분 구조 포함), 그 달 일정, 앞뒤 달에 걸친 날짜가 들어오고, 다음 달 일정이 자동 생성됩니다.
3. 올렸던 원본 탭(`10월 근무표`)은 지워도 됩니다.

> 같은 이름·같은 팀은 기존 사람으로 인식하므로 나중에 다시 가져와도 관리자 설정이 유지됩니다.

### 4. 관리자 지정
**근태관리 > 3. 관리자 지정 / 비밀번호 변경** → 성명, 비밀번호, 요약 메일 받을 이메일을 입력합니다. 몇 명이든 지정할 수 있고,
이후에는 웹앱의 **관리 > 인원** 화면에서도 관리자를 지정·해제할 수 있습니다.

### 5. 웹앱 배포
1. Apps Script 편집기 오른쪽 위 **배포 > 새 배포** → 유형 **웹 앱**
2. **실행 사용자: 나** / **액세스 권한: 모든 사용자** (구글 로그인 없이 링크로 접속)
3. **배포** → 나오는 `https://script.google.com/macros/s/…/exec` 주소를 팀 단톡방 등에 공유합니다.
   (휴대폰에서 열고 *홈 화면에 추가* 하면 앱처럼 쓸 수 있습니다.)

> 코드를 고친 뒤에는 **배포 > 배포 관리 > ✎ > 버전: 새 버전 > 배포** 를 해야 같은 주소에 반영됩니다.

## 운영 메모

- **팀원 화면에서 인원 추가/빼기** 는 관리자만 보입니다. 추가한 사람은 이번 달부터 기본 근태(주간, 일요일 빈칸)로 채워지고, 뺀 사람은 지난 기록이 남되 이후 화면·추출에서 빠집니다.
- **근태 목록**(`근태코드` 탭 또는 관리 화면): 표기·색상·근무형태 여부·기본형·집계 묶음. 표기는 엑셀 양식과 같게 적어야 집계가 맞습니다 (칸 안 줄바꿈 포함, 예: `1Shift` + 줄바꿈 + `(OT)`).
  - *근무형태* 인 것만 새 달 기본 근태 계산에 들어가고, *기본형* 이 있으면 그쪽으로 합산합니다 (`1Shift(OT)` → `1Shift`).
  - *집계 묶음* (`1Shift`/`주간`/`2Shift`)은 엑셀 하단 집계표와 시간별 근무인원 계산에 쓰입니다. `주간2` 는 `주간` 묶음입니다.
- **조직표기** 탭: 소속·구분 이름 뒤에 인원수 `(81)` 를 붙일지와 모양(줄바꿈/공백). 엑셀을 가져오면 자동으로 채워지고, 추출할 때 인원수는 자동 계산됩니다.
- **월별 일정 탭** `일정_2026-10` 등은 관리자가 시트에서 직접 봐도 되지만, 수정은 웹앱에서 하는 것을 권장합니다 (시트에서 직접 고치면 변경 이력·실시간 반영이 되지 않음).
- **요약 메일** 은 15시~16시 사이에 발송됩니다 (구글 자동 실행 특성). 관리자 이메일이 하나도 없으면 시트 소유자에게 갑니다. 변경이 없으면 보내지 않습니다.
- **21일 이전** 에는 다음 달 탭의 마지막 주 중 다다음 달 날짜가 "미생성"(빗금)으로 보입니다. 21일 새벽 자동 생성 후 수정할 수 있습니다.
- 무료 구글 계정 한도: 동시 실행 30건, 메일 하루 100통 — 수십~백여 명 부서에서 충분합니다.

### 기존 엑셀 대비 달라진 점 (집계표)
기존 양식 하단 집계 수식은 건축 범위가 `5~83행`, `5~85행`으로 고정돼 있어 서무 일부 인원과 `2Shift(조출)` 이 집계에서 빠져 있었습니다.
추출 파일은 팀(건축/안전) 전체 인원과 각 묶음의 모든 변형을 자동으로 범위에 넣습니다.

## 개발

```
src/            Apps Script 코드 (그대로 붙여넣는 파일)
  Logic.gs      날짜·기본 근태·조직 병합·엑셀 양식 레이아웃 (순수 로직)
  Store.gs      시트 읽기/쓰기
  Api.gs        웹앱 진입점, 화면에서 부르는 함수, 관리자 인증
  Jobs.gs       자동 실행 (월 생성, 15시 메일)
  Export.gs     엑셀 추출
  Import.gs     엑셀 양식 가져오기
  Setup.gs      시트 메뉴, 처음 설정
  Index.html    모바일 화면
tools/
  test.mjs          서버 시나리오 테스트 (가짜 Apps Script 환경)
  build-preview.mjs 서버 없이 화면 미리보기 생성 (mock-server.js 사용)
```

```bash
node tools/test.mjs                                   # 테스트
python3 tools/sheet_to_json.py 근무표.xlsx /tmp/s.json && node tools/test.mjs /tmp/s.json   # 실제 양식으로 테스트
node tools/build-preview.mjs preview/index.html       # 화면 미리보기
```
